## Key Theories

### Flow State
Optimal experience when:
- Challenge matches skill
- Clear goals exist
- Immediate feedback provided
- Player feels in control

### Player Types (Bartle)
- **Achievers**: Goal-oriented, completion
- **Explorers**: Discovery, experimentation
- **Socializers**: Interaction, community
- **Killers**: Competition, dominance

### Motivation (Self-Determination Theory)
- **Autonomy**: Player choice
- **Competence**: Skill mastery
- **Relatedness**: Social connection

### Engagement Loops
- Action → Feedback → Reward → Motivation
