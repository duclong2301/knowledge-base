## Core Concepts

### Mechanics Categories
- **Movement**: How players navigate
- **Actions**: What players can do
- **Resources**: What players manage
- **Progression**: How players improve
- **Challenge**: What opposes players

### Design Process
1. Define core verbs
2. Prototype quickly
3. Test and iterate
4. Balance and polish
5. Layer complexity gradually

### Feedback Systems
- Visual feedback
- Audio feedback
- Haptic feedback
- UI feedback
- Reward feedback
